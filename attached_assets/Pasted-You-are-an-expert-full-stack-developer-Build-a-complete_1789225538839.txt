# 5. GitHub OAuth

Implement complete GitHub OAuth.

Flow:

```text
User clicks Login with GitHub
        ↓
Redirect to GitHub authorization
        ↓
User grants permission
        ↓
GitHub redirects to callback
        ↓
Backend exchanges code for access token
        ↓
Backend fetches GitHub profile
        ↓
Secure session/cookie is created
        ↓
User is redirected to dashboard
```

Create these routes or equivalent:

```text
/api/github/auth
/api/github/callback
/api/github/profile
/api/github/repositories
/api/github/commits
/api/github/sync
/api/auth/logout
```

Use environment variables:

```env
GITHUB_CLIENT_ID=
GITHUB_CLIENT_SECRET=
GITHUB_REDIRECT_URI=
```

Support both local and production callback URLs.

Do not hardcode secrets.
